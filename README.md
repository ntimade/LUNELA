# LUNELA

Mobile health-education app focused on women's cycle and reproductive health, built with React Native (Expo) and Firebase.

## Features

- Menstrual cycle tracking with a calendar, and cycle sharing with a partner
- Symptom and health entries
- Contraceptive information
- Educational content and quizzes
- Community forum with moderation
- Chat and specialist accounts (registration and admin approval)
- Screens that help male partners understand the cycle and share responsibility
- Admin dashboard: content, quizzes, surveys and reports, forum moderation
- Notifications, multi-language support, light and dark themes

## Tech stack

React Native, Expo, Firebase (authentication, Firestore, Storage), local database with a sync service.

## Getting started

    npm install
    npx expo start

Create your own Firebase project and update the configuration in src/config/firebase.js.
